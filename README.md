# 目标可用性人工标注

在线标注页：https://ustbmicl-ros2epucksRL.github.io/target-usability-annotation/

1. 用 Chrome 或 Edge 打开上面的网址，在页面上方填写姓名缩写。
2. 按页面顶部说明，用数字键 1–5 为 139 张图各选一个选项，约 20–30 分钟。请独立完成，不要与他人讨论。
3. 结果自动保存在当前浏览器；中途关闭后用同一浏览器重新打开、填同一缩写即可继续。不要用无痕模式。
4. 标完点“导出”，把下载得到的 `annotation_缩写.json` 直接发给负责人（不要上传到本仓库，以免其他标注员看到）。

本仓库只包含标注页面与 139 张合成渲染图，不含参考答案。
